# DEF-001

**Issue**: Running `supabase db push` in dry‑run mode incorrectly attempts to execute pending migrations, causing failures when functions dependent on `is_admin()` and `is_super_admin()` are altered.

**Resolution**: Updated documentation to state that dry‑run only lists pending migrations and does **not** execute any SQL.

**Location**: `docs/testing/defects/DEF-001.md`
